# Sifarma
Aplikasi Farmasi merupakan aplikasi berbasis web yang berfungsi sebagai layanan microservice dalam ekosistem Sistem Informasi Manajemen Rumah Sakit (SIMRS). Aplikasi ini dirancang untuk mendukung dan mengelola seluruh proses pelayanan kefarmasian secara terintegrasi, akurat, dan real-time, mulai dari penerimaan resep hingga pelaporan farmasi.

Aplikasi Farmasi terintegrasi langsung dengan modul SIMRS lainnya seperti pendaftaran pasien, pelayanan medis, rawat jalan, rawat inap, dan keuangan, sehingga memastikan kesinambungan data dan meminimalkan duplikasi input. Seluruh transaksi farmasi mengacu pada data pasien, dokter, dan tindakan yang telah tercatat di SIMRS.

Sebagai microservice, aplikasi ini dikembangkan dengan arsitektur yang modular, scalable, dan berbasis API, sehingga mudah dikembangkan, dipelihara, serta diintegrasikan dengan sistem lain seperti e-Resep, e-Catalog, BPJS, dan sistem pihak ketiga.
